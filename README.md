# ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/ChaitanyaBhatt147/Angular.git
cd Angular
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run the Angular application

```bash
ng serve
```
